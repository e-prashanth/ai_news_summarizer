## Highlights

### Anthropic Debuts on Nasdaq Raising Over $80 Billion
Anthropic launched its initial public offering on Nasdaq at $83 per share, raising over $80 billion in capital and opening at $111 per share. Investors are weighing the company's safety strategy and public concerns regarding data center expansion against its overall growth.
Source: [TechCrunch AI](https://techcrunch.com/2026/11/19/anthropic-hits-nasdaq-exchanges-at-110-27-above-ipo-price/) | [Wired AI](https://www.wired.com/story/anthropics-record-breaking-ipo-highlights-the-ai-giants-worst-enemy-itself/)

### Google Brings Gemini AI Agent to macOS
Google released an update bringing an AI agent powered by Gemini to Mac devices. The agent is designed to manage multistep workflows, fill out forms, and organize files on the computer.
Source: [TechCrunch AI](https://techcrunch.com/2026/11/19/google-gives-gemini-the-ability-to-use-your-mac-for-you/)

### OpenAI Releases Real-Time Live Dictation for ChatGPT
OpenAI introduced Live Dictation for ChatGPT across web, desktop, iOS, and Android platforms for all plan tiers. The feature transcribes microphone audio in real time as the user speaks instead of processing the audio after recording stops.
Source: [The Verge AI](https://www.theverge.com/ai-artificial-intelligence/1037634/openai-chatgpt-live-dictation)

### Meta’s Muse AI Agent Reportedly Exposes Private User Data
An internal report indicates that Meta's AI agent Muse has been conflating user conversations and leaking private data. Employees reported that Muse displayed messages regarding unrequested childcare, career advice, product orders, and external bank account balances.
Source: [TechCrunch AI](https://techcrunch.com/2026/11/19/metas-ai-agent-muse-is-mixing-up-conversations-and-exposing-private-data-report-says/)

### Google Tests Chrome AI Browsing Agents in "Mirror Dimension" Sandbox
Google created a simulated "mirror dimension" internet environment to train and test AI browsing agents for Chrome. The sandbox environment lets developers evaluate agent behavior safely without risk to the live web.
Source: [Wired AI](https://www.wired.com/story/google-built-a-giant-mirror-dimension-internet-to-test-its-chrome-ai-agents/)

### Canva Introduces Opt-Out Toggle for Generative AI
Canva added a dedicated toggle enabling users to turn off generative AI features across its graphic design platform. The control lets users disable tools like the Magic Expand image extender and image generation via the Canva chatbot.
Source: [The Verge AI](https://www.theverge.com/ai-artificial-intelligence/1037126/canva-ai-features-off-button)

### OpenAI Details Performance Factory and Security Tools
OpenAI detailed its "Performance Factory," an automated system powered by Codex workflows designed to find and fix latency issues in ChatGPT. OpenAI also published reference architectures and walkthroughs for security tools, including Daybreak Red, PR scans, and the Codex Security Plugin.
Source: [OpenAI News](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast)

### Google Launches Tool Retrieval in Gemini API
